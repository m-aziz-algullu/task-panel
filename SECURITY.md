# Security Policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately through GitHub: go to the repository's **Security** tab and click **Report a vulnerability**. You'll get a reply as soon as possible, and a fix will be released before the issue is disclosed.

Helpful details: affected version or commit, steps to reproduce, and the impact you see.

## Supported versions

Only the latest release on `main` receives security fixes.
